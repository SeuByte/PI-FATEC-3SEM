# 🌱 Janete Produtos Naturais - Sistema E-commerce e Gestão

## Sobre o Projeto

O projeto **Janete Produtos Naturais** nasceu com o objetivo de modernizar e centralizar toda a operação da empresa em uma única plataforma.

Atualmente muitos processos acabam ficando distribuídos entre controles manuais, planilhas ou diferentes sistemas. Com isso surgiu a necessidade de desenvolver uma solução completa que não apenas permita a venda dos produtos pela internet, mas também organize a gestão interna da empresa.

O sistema está sendo desenvolvido como um **E-commerce integrado a um sistema administrativo**, permitindo que a empresa tenha mais controle, organização e praticidade em suas operações diárias.

---

# 🎯 Objetivos do Projeto

O sistema terá como foco principal:

- Disponibilizar uma loja virtual para venda de produtos naturais
- Centralizar e controlar o estoque
- Facilitar o gerenciamento de produtos
- Organizar pedidos e vendas
- Gerar dashboards para acompanhamento dos resultados
- Auxiliar na tomada de decisões através de dados

---

# 🚀 Funcionalidades previstas

### Área do Cliente

- Cadastro e login de usuários
- Catálogo de produtos
- Pesquisa de produtos
- Carrinho de compras
- Finalização de pedidos
- Histórico de compras
- Perfil do cliente

### Área Administrativa

- Cadastro de produtos
- Gerenciamento de estoque
- Controle de entradas e saídas
- Gestão de pedidos
- Controle de clientes
- Relatórios gerenciais

### Dashboards

- Produtos mais vendidos
- Faturamento
- Controle de estoque
- Vendas por período
- Indicadores gerais
- Métricas para tomada de decisão

# ⚙️ COMO RODAR O PROJETO

Instale o Virtual Environment:

```bash
pip install virtualenv
python -m virtualenv venv
```

## WINDOWS

```bash
cd venv
cd Scripts
activate.bat
cd ../..
```

## LINUX

```bash
source venv/bin/activate
```

---

## 📦 INSTALAR DEPENDÊNCIAS

```bash
pip install -r requirements.txt
```

---

## ▶️ INICIAR PROJETO

```bash
python manage.py runserver
```
