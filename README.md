# COMO RODAR O PROJETO
```
    pip install virtualenv
    python -m virtualenv venv
```
## WINDOWS
```
    cd venv
    cd Scripts
    activate.bat
    cd ../..
```
## LINUX
```
    source .venv/bin/activate
```
## INSTALAR DEPENDÊNCIAS
```
    pip install -r requiriments.txt
```
## INICIAR PROJETO
```
    python manage.py runserver
```
